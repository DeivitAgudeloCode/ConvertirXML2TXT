📄 ConvertirXML2TXT

ConvertirXML2TXT es una aplicación desarrollada a medida para una empresa que requería transformar archivos XML puros en archivos TXT descargables, siguiendo una sintaxis específica que permite validar correctamente las conversiones realizadas.

El programa realiza el mapeo de datos desde XML, asegurando que la información se estructure de forma precisa en el archivo de texto final, de acuerdo con las reglas definidas por el negocio.

🛠️ Tecnologías utilizadas

C#

XML (mapeo y estructuración de datos)

🎯 Objetivo del proyecto

Automatizar la conversión de archivos XML a formato TXT, garantizando consistencia, validación y facilidad de uso en entornos empresariales.
