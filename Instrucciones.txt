1. El programa solo funciona en .NET 8 : https://builds.dotnet.microsoft.com/dotnet/Sdk/8.0.419/dotnet-sdk-8.0.419-win-x64.exe

2. Ingresar al programa y dirigirse al archivo llamado input.xml.

3. Ingresar los registros en xml desde la etiqueta <ROW> hasta la ultima <ROW>, la equiqueta <ROWSET> no aplica
y colapsara el archivo.

4. luego usar el comando de dotnet run (-- -i input.xml -o salida.txt -m reglas.mapeo.json)-incluir en caso de que
hayan problemas al momento de ejecutarlo el cual permite al programa leer el xml y adaptarlo al archivo en formato texto.

5.En caso de querer cambiarle el nombre al archivo se hara desde el comando --o (nombre del archivo).txt.

6. cada vez que se quiera hacer una modificacion se debera guardar o eliminar el archivo de salida.txt. Ya que este 
no se autoincrementa si no que se sobreescribe.

7. el programa ejecuta la funcion de a nombre de SEVEN.TODO(validar a nombre de quien corresponde el proyecto).

8. en caso de querer modificar el nombre del servicio ej:tw.local.sevenTodo. se debera de escribir en el terminal junto al comando 
(-n (nombre del servicio)), este automaticamente modificara el archivo y lo insertara de no agregar nada el valor 
predeterminado sera sevenTodo.
